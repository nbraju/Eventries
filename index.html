Wedding Setup SOP

Purpose: To provide a seamless, elegant, and timely setup for wedding ceremonies and receptions.

Scope

Covers all tent house services for weddings including mandap, reception area, dining, stage, lighting, and seating.

Roles

  • Site Supervisor: Overall coordination, client liaison, quality check.
  • Crew Lead: Manages on-ground labour, assigns tasks.
  • Technician: Handles electrical, lighting, and sound systems.
  • Driver/Logistics: Transports materials and ensures timely delivery.

Pre-Event Planning (7–14 days prior)

  • Client Consultation: Confirm venue layout, guest count, and specific requirements.
  • Inventory Selection: Tents, seating, stage, flooring, lighting, sound.
  • Site Survey: Assess ground conditions, slope, and obstacles.
  • Logistics Planning: Schedule delivery and setup time (1–2 days before event).

On-Site Setup (1–2 days before event)

  • Site Preparation: Clear debris, level ground, lay tarpaulin.
  • Tent/Pandal Installation: Erect poles, secure with ropes, install canopy.
  • Stage Construction: Assemble stage platform, install backdrop.
  • Seating & Dining Layout: Arrange chairs, tables, buffet counters.
  • Lighting & Electrical: Run cables, install decorative lights, test connections.
  • Final Walkthrough: Check alignment, aesthetics, and safety.

Event Day Operations

  • Supervisor on-site, power backup available, monitor weather.
  • Assist with guest flow and accessibility.

Teardown & Cleanup

  • Dismantle tents and structures carefully, pack items, clean venue.

Post-Event Review

  • Collect client feedback, document damages, update inventory.

Birthday Events SOP

Purpose: To create a fun, safe, and vibrant setup for birthday celebrations.

Scope

Small to medium-sized birthday parties (20–100 guests) with tenting, seating, and themed decorations.

Roles

  • Event Coordinator: Liaises with client, manages on-ground team.
  • Decorator: Handles balloons, banners, centrepieces.
  • Crew: Tent erection, furniture placement.

Pre-Event Planning (5–7 days prior)

  • Determine guest count, age group, and theme.
  • Select tent/canopy, plastic chairs, themed decorations, sound system.
  • Site assessment: layout for activity, dining, cake table.

On-Site Setup (day of event, 3–4 hours before)

  • Clean area, erect tent/canopy, arrange seating.
  • Set up decorations: balloon arches, table centrepieces, cake table.
  • Install sound system, place garbage bins.

Event Day Operations

  • Monitor children’s activities, ensure food stations accessible.

Teardown & Cleanup

  • Dismantle decorations, fold chairs, pack tents, clean venue.

Corporate Conferences SOP

Purpose: To deliver a professional, tech-enabled setup for corporate meetings and conferences.

Scope

Registration area, main hall, breakout rooms, catering spaces.

Roles

  • AV Specialist: Sound, projectors, screens, recording.
  • Logistics Manager: Coordinates furniture, signage, and materials.
  • Crew: Tent/stage setup and furniture placement.

Pre-Event Planning (7–10 days prior)

  • Obtain agenda, number of attendees, AV requirements.
  • Select large span tents, conference chairs, stage, AV equipment, lighting.
  • Site survey: acoustics, power capacity, internet connectivity.

On-Site Setup (1 day before conference)

  • Erect tents, set up stage and seating, install AV equipment.
  • Place furniture, registration desk, signage.
  • Test all equipment, run through session flow.

Event Day Operations

  • AV technician on standby, seamless transitions, crowd management.

Teardown & Cleanup

  • Dismantle AV equipment, pack furniture, clean venue.

Political Meetings SOP

Purpose: To provide a robust, secure, and functional setup for political rallies and public meetings.

Scope

Large gatherings (500–10,000+) with stage, sound, seating, and crowd control barriers.

Roles

  • Site Supervisor: Coordinates with event organisers and security.
  • Sound Engineer: Manages PA system and mics.
  • Security Liaison: Works with local authorities for safety.

Pre-Event Planning (10–14 days prior)

  • Risk assessment, coordinate with police for permissions.
  • Select large tents, heavy-duty stage, PA system, seating, barriers.
  • Site survey: ground stability, power source, medical aid.

On-Site Setup (1–2 days prior)

  • Erect stage with ramp, install backdrop.
  • Set up PA system, test coverage.
  • Arrange VIP seating, install barriers, signage.
  • Connect to main power and generator.

Event Day Operations

  • Secure stage, audio check, monitor crowd pressure, coordinate with security.

Teardown & Cleanup

  • Dismantle stage and sound, remove barriers, clean site.

Temple Festivals SOP

Purpose: To facilitate religious festivals by setting up temporary structures for rituals, prasad distribution, and devotee accommodation.

Scope

Mandap, kitchen, dining, queue management.

Roles

  • Religious Coordinator: Liaises with temple priests and management.
  • Logistics Crew: Sets up tents, seating, and catering areas.
  • Sanitation Team: Manages waste and cleaning.

Pre-Event Planning (7–10 days prior)

  • Understand festival schedule, rituals, expected crowd.
  • Select large mandaps, temporary sheds, plastic chairs, cooking area, queue barriers.
  • Site survey: ground condition, water availability, waste disposal.

On-Site Setup (2–3 days prior)

  • Erect mandap with side coverings, place altar/deity platform.
  • Set up temporary kitchen, dining area, serving counters.
  • Install queue barriers, shade for waiting devotees.
  • Place portable toilets and garbage bins.

Event Day Operations

  • Ensure fire extinguishers handy, monitor food safety, coordinate volunteers.

Teardown & Cleanup

  • Dismantle structures after final rituals, clean temple premises.

School Annual Days SOP

Purpose: To organise a vibrant, safe, and professional setup for school annual day functions.

Scope

Stage, seating, sound, lighting, backstage arrangements.

Roles

  • Event Manager: Coordinates with school staff and teachers.
  • Stage Crew: Builds stage, manages props.
  • AV Technician: Sound, lighting, presentation.

Pre-Event Planning (10–14 days prior)

  • Obtain program schedule, number of performers, audience size.
  • Select stage with backdrop, chairs, sound system, lighting.
  • Site survey: power capacity, rain contingency plan.

On-Site Setup (1 day before)

  • Build stage with appropriate height, install backdrop.
  • Arrange seating: dignitaries, students, parents.
  • Install speakers, mics, projector.
  • Set up backstage with changing tents.
  • Install stage lighting and ambient hall lighting.

Event Day Operations

  • Conduct sound check and light rehearsal, coordinate with teachers, ensure safety.

Teardown & Cleanup

  • Dismantle stage, AV, and seating, clean venue, collect feedback.

Cross-Event Best Practices

  • Safety First: Site risk assessment and first-aid kit on site.
  • Power Backup: Generator for critical systems.
  • Communication: Walkie-talkie or phone contact among crew.
  • Weather Preparedness: Contingency for rain/wind.
  • Client Feedback: Gather feedback to improve future events.

🔑 Pro Inventory Tips for Hyderabad Vendors

  • Always stock 10% extra chairs — late arrivals and gate-crashers are common at Indian weddings.
  • Keep monsoon backup tents in stock year-round; Hyderabad pre-monsoon showers start as early as April.
  • White chair covers get stained fastest — maintain a 20% surplus of covers vs. chairs.
  • For summer events (Mar–Jun), pedestal fans and air-coolers are non-negotiable; guests will walk out otherwise.
  • Label every item with a QR code or serial number — theft and mix-ups at multi-vendor venues are frequent.
  • Store 3-phase power cables for large events; most banquet halls in Gachibowli/Hitech City have 3-phase supply.
